# Contributing to RestaurantApp

Thanks for contributing to RestaurantApp.

## Before opening a pull request

- Keep changes focused and include relevant tests when behaviour changes.
- Run the applicable Gradle checks for the modules you change.
- Do not commit credentials, private keys, generated build output, or third-party assets unless their licensing and attribution are documented.
